# Character: Xiaohei

## Swapping the character

This file defines the recurring character. To use a different character, replace only this file. The rest of the skill works with any character as long as it follows the rule that the character performs the core action.

## Definition

Xiaohei ("little black one") is the recurring visual character of these illustrations.

Xiaohei appears in every image by default. Xiaohei is not a mascot, not a sticker, and not a cute decoration. Xiaohei is an absurd worker who is seriously taking part in how the system runs.

## Appearance

- A small solid-black creature.
- White dot eyes.
- Thin legs, sometimes thin arms.
- The body can be a cylinder, a black bean, a black box, a funnel, a shadow, a hole, or a black block inside a machine.
- Slightly irregular outline with a hand-drawn feel.
- Blank, dazed, calm, serious expression.

## Personality

- Very serious, but what it does is a bit absurd.
- Like a low-key system operator.
- Dry humor, never acting cute.
- A little clumsy, but not stupid.
- Looks like it really is responsible for some job inside a whiteboard sketch.

## Typical jobs

Give Xiaohei the core action:

- Carrying material.
- Pulling lines to gather information sources.
- Getting stuck inside a breakpoint.
- Operating a "judgment" lever inside a machine.
- Becoming a filtering funnel.
- Slicing open a "material fish".
- Stamping handoff scripts.
- Leading a handoff path on a leash.
- Holding up a warning sign next to a pit.
- Reaching out of a hole but failing to catch the content.
- Nearby: laying bricks, building a bridge, opening a door, sorting, taking notes.

Several of these are already used in past examples. See the anti-copy list in references/composition-patterns.md before reusing one.

## Forbidden

- Do not draw Xiaohei as an overly cute mascot.
- Do not draw it as a children's cartoon character.
- No complex outfits, meme faces, or sparkly eyes.
- Do not let Xiaohei just stand in a corner and watch.
- Do not let Xiaohei steal attention from the structure.
- Do not make Xiaohei too commercial, too round, or too polished.

## Key test

If you remove the character and the core metaphor still fully works, the character is decoration. Rewrite the prompt so the character becomes the subject of the action.
